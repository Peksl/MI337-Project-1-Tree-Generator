# MI337-Project-1-Tree-Generator

Guide to using the "TreeGen" Geometry Node in Blender

TreeGen guide:

Used to create a curvy tree with many different trunks at the base

1. Create any mesh object
2. With that object, in the Geometry Nodes window, press "New" and select "TreeGen" in the pulldown tab.
3. In the modifiers panel you can adjust the Tree Seed, Trunk Amount, Tree Height, Rotation Axis, Curve Direction, and Leaf Size
4. Once final model is made, apply the "TreeGen" modifier
5. Create LOD's of the model by decimating it 3 times in varying intensity.
6. Export all LOD's together
